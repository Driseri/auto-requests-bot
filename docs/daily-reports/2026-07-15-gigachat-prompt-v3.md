## Что улучшено в prompt V3

- Проверка оценивает заявку как единое описание, собранное из четырёх содержательных разделов, а не требует, чтобы каждый факт находился в конкретном поле.
- Уточнены критерии содержания изменения, ситуации применения и основания/логики изменения существующего ответа.
- Общие фразы, ссылки и формальные слова сами по себе больше не считаются достаточным подтверждением критерия.
- Разрешены морфологические формы, местоименные связи и смысловые синонимы, если смысловая связь однозначна.
- Для новой сущности и изменения существующего ответа применяются разные правила, включая отдельное правило для текущего состояния ответа.
- При неполном описании сохраняется формат одного главного блокера и одной конкретной инструкции для уточнения.
- Направление, тип ответа, тип изменения и сценарист не передаются в user prompt, поскольку не должны влиять на оценку полноты заявки.

## Важное для эксплуатации

- В локальном тестовом контейнере отключена проверка TLS-сертификата GigaChat из-за ошибки `self-signed certificate in certificate chain` в локальной сети. Это сделано только для тестовой среды и не должно переноситься в production без отдельного решения по сертификатам.
- В production перед включением V3 необходимо проверить, что переменные `GIGACHAT_SYSTEM_PROMPT_PATH` и `GIGACHAT_USER_PROMPT_PATH` указывают на версии V3.
- Для проверки работы промпта в логах используются события начала проверки GigaChat, получения ответа и итогового результата; полный текст заявки и credential в логи не выводятся.
